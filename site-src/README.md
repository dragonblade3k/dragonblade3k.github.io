# Site source

React and Tailwind source for shantanusirjoshi.com. GitHub Pages serves the repo root.

    npm ci
    npm run build

The build replaces `index.html` and `static/` at the root. Photos, `resume.pdf`, `CNAME` and `apps/` are not touched.

Project cards live in `src/data/content.js`. Live apps live in `/apps`.
